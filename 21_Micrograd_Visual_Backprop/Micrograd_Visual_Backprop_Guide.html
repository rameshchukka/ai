📘 Concept Notes

Forward pass is just evaluating an expression, remembering every step

Nothing about a neural network's forward pass is conceptually different from evaluating a small arithmetic expression left to right. The only extra ingredient is remembering intermediate values -- which is exactly what wrapping numbers in a Value class does.

A Value is a number that remembers its own computation graph

Plain Python numbers forget where they came from. A Value stores which operation and which inputs produced it, so the entire history of a computation becomes a traversable graph -- which is what makes backpropagation possible at all.

Backprop is local rules plus one global algorithm

Each operation only needs to know its OWN local derivative (+ gives 1, * gives the other input). The global part -- topological sort, then walk in reverse -- is a real, general graph algorithm, not something special to neural networks.

Values used more than once must ADD their gradient contributions

The single most common backprop bug, done by hand or in code: overwriting a gradient instead of accumulating it when a value feeds into more than one place. This is exactly why every _backward() function uses += rather than =.

💡 Tips & Pitfalls

Tips

  • Render the graph after EVERY new concept -- the picture is the point of this lab.
  • Use numerical gradient checking (tiny epsilon nudge) to sanity-check any new operation you add.
  • Rewatch Karpathy's video after finishing -- every line will now be familiar.

Common Pitfalls

  • Overwriting a gradient with = instead of accumulating with += when a value is reused.
  • Running _backward() in the wrong order (must be reverse topological order).
  • Forgetting to zero gradients between training steps -- they accumulate by design.

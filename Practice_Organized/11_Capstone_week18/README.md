# Capstone Kickoff (Week 18)

Lab 5 working files. This lab is scoping-focused, not code-heavy — the deliverable is a
well-defined plan, not a working system (that's Month 6). Pairs with:
- `Month4_Modern_AI_Agentic_Stack_Course.md` — Week 18 concept notes
- `Guided_Labs_UserGuide.html`, Lab 5 — timing + checkpoints
- `GEMINI_NOTES.md` / `OPENROUTER_NOTES.md` — provider-specific details (same as Labs 1-4)

## Setup

```bash
pip install -r requirements.txt
cp .env.example .env
# edit .env: set LLM_PROVIDER=gemini_auto (recommended), plus GEMINI_API_KEY and OPENROUTER_API_KEY
```

## Files

| File | What it does |
|---|---|
| `scoping_doc_template.md` | Fill in like a real discovery-call writeup — problem, current process, success criteria, constraints, out-of-scope |
| `mvp_cut_template.md` | List 10 features, cut to 3, justify every cut |
| `architecture_template.md` | Sketch data → RAG → agent → eval/guardrail → output, tying back to Labs 2-4's actual patterns |
| `discovery_questions_template.md` | Your final 5 discovery questions, plus notes from the roleplay session |
| `stakeholder_roleplay.py` | **Interactive** — the model role-plays a non-technical stakeholder in your chosen industry so you can practice a live discovery conversation, then gives you coaching feedback on your questions |
| `capstone_scaffold/` | Working infra scaffold — a minimal "hello world" proving the plumbing works, ready for Month 6's real build |

## Recommended order

1. Read `scoping_doc_template.md`'s prompts, pick your industry/use case, but don't fill
   in Success Criteria or Constraints yet.
2. Run `python stakeholder_roleplay.py` — practice a live discovery conversation first.
   **This needs a real provider** (`gemini_auto` or `openrouter`) — mock mode can't
   role-play a convincing stakeholder, it'll just return a generic fallback message.
3. NOW fill in `scoping_doc_template.md` completely, using what you learned from the
   roleplay.
4. Fill in `mvp_cut_template.md`.
5. Fill in `architecture_template.md`.
6. Distill your best 5 questions into `discovery_questions_template.md`, referencing the
   roleplay transcript.
7. `cd capstone_scaffold`, set it up, run `python src/main.py` to confirm the infra works.

## Before you `git push`

- [ ] `.env` is NOT staged (check both the top-level and `capstone_scaffold/` folders)
- [ ] All 4 template `.md` files are filled in — rename them by dropping `_template`
      once complete (e.g. `scoping_doc_template.md` → `scoping_doc.md`)
- [ ] `discovery_transcript.md` exists (generated by `stakeholder_roleplay.py`)
- [ ] `capstone_scaffold/src/main.py` runs cleanly against a real provider, not just mock

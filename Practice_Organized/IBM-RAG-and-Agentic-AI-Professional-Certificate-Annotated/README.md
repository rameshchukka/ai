## Lab Highlights

### Module 1 — Generative AI & Structured Extraction

**M1L1 · Extract Structured JSON from Unstructured Text**  
Uses an LLM to parse raw restaurant descriptions from a California culinary map into structured JSON. Demonstrates prompt engineering for reliable schema-constrained output.

**M1L2 · Process Multimodal Data with LLMs**  
Processes food recipes combining textual descriptions and images. Introduces multimodal prompting and JSON-augmented recipe generation.

**M1L3 · Command-Line Data Management**  
Builds an interactive CLI tool that uses LLMs to manage and query structured data, demonstrating LangChain chains and agents for data manipulation.

---

### Module 2 — Multimodal Vector Retrieval

**M2L1 · Construct a Multimodal Vector Index**  
Builds parallel vector indexes for restaurant articles (Sentence-Transformers) and food images (CLIP) using Chroma, establishing an indexing infrastructure for heterogeneous data.

**M2L2 · Similarity Retrieval with Metadata Filtering**  
Implements the retrieval layer: executing similarity searches against the vector indexes with optional metadata constraints for precision-oriented retrieval.

**M2L3 · Multimodal Similarity Fusion & Retrieval Ranking**  
Implements cross-modal score normalization and weighted fusion to merge text and image retrieval results into a unified ranked list — mirroring production-grade multimodal RAG systems.

---

### Module 4 — Model Context Protocol (MCP)

**M4L1 · Build an MCP Server** *(Course 9)*  
Implements a FastMCP server exposing the California Culinary Map dataset as an MCP resource, with three tools for searching and retrieving restaurant information.

**M4L2 · Build an MCP Client** *(Course 9)*  
Builds an MCP client that connects to the server via `ClientSession` over stdio, implementing roots and sampling callbacks, and invoking all server tools through the MCP protocol.

**M4L3 · Design a Full LLM MCP Host** *(Course 9)*  
Assembles a complete MCP host application: a Gradio chat interface backed by WatsonX, running a ReAct agent loop that discovers MCP tools at runtime, invokes them iteratively, and renders natural language responses.

## Getting Started

Each lab folder is self-contained. Refer to the `lab-instructions.md` (where present) for environment setup specific to that lab. General setup:

```bash
# Clone the repository
git clone https://github.com/kevinha98/IBM-RAG-and-Agentic-AI-Professional-Certificate.git
cd IBM-RAG-and-Agentic-AI-Professional-Certificate

# Create and activate a virtual environment (per lab)
python -m venv .venv
source .venv/bin/activate      # macOS/Linux
.\.venv\Scripts\activate       # Windows

# Install dependencies (varies per lab — check lab-instructions.md)
pip install -r requirements.txt
```

> **Note:** Labs using IBM WatsonX require an IBM Cloud account and API key. Set the `WATSONX_API_KEY` and `WATSONX_PROJECT_ID` environment variables before running those notebooks.

02 L1 — Models, Prompts & Output Parsers

notebook L1

From raw API calls to templates and parsers

Concept: contrasts a raw OpenAI call with LangChain's ChatModel + PromptTemplate + OutputParser. The parser turns a free-text reply into structured fields.

✔ Worked answer / expected output

The raw call and the LangChain call return the same answer, but the LangChain version is reusable and the output parser returns a Python dict (e.g. extracting sentiment/fields from a review) instead of a blob of text. That structured dict is the payoff.

03 L2 — Memory

notebook L2

Four memory types

Concept: ConversationBufferMemory (keep everything), BufferWindow (last k turns), TokenBuffer (last N tokens), Summary (compress old turns).

✔ Worked answer / expected output

Buffer memory makes the bot recall earlier turns; window/token memory deliberately 'forget' older context to save tokens — you'll see an early fact dropped once it falls outside the window. The lesson: memory is a cost/recall trade-off you choose.

04 L3 — Chains

notebook L3

LLMChain → Sequential → Router

Concept: compose steps. Sequential chains feed one output into the next; a router chain picks a sub-chain based on the input.

✔ Worked answer / expected output

SimpleSequentialChain passes a single output forward; SequentialChain threads several named variables; the RouterChain sends a physics question to the physics prompt and a math question to the math prompt. You'll see the router print which destination it chose.

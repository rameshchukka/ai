08 Notebook 07 — Chroma + Postgres together

notebook 07

Vector DB and relational DB in one workflow

Chroma for semantic search, Postgres for the structured facts, joined on an id.

SectionWhat it does & what to expect
1. Chroma setupthe vector layer
2. Postgres setupthe relational layer
3. Joined querysemantic search returns ids → SQL fetches the rows

A query is embedded and matched in Chroma to get ids; Postgres then returns the authoritative structured record for those ids. The pgvector option collapses both into one database — exactly the trade-off from your API pgvector exercises.

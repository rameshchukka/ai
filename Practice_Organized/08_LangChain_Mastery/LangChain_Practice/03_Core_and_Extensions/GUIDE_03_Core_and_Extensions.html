02 Study order

The 'without → with framework' philosophy

This material's whole design is to show you each concept by hand first, then with LangChain — so the framework never feels like magic. Follow that arc:

  1. Core_LangChain first: rag_pure_python.py → rag_langchain_faiss.py → rag_langchain_chroma.py (see learning_guide.md there for the phase plan).
  2. Extensions next: notebooks 01→07 in order. The 02/03 and 04/05 pairs are deliberately 'without then with LangChain'.
  3. Real_World_Exercises last: apply it, using that folder's own guides.

03 In-house models (offline-safe)

No HuggingFace downloads required

Unlike the external courses in 04_external_courses/, this material is wired to your in-house models via Core_LangChain/llm_provider.py and the .env.office.example / .env.personal.example templates. Copy the one matching where you're running to .env. That's why this is the safest to run on your org network.

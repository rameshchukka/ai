01 About this project

A deployable chatbot application, not a tutorial — an API, a UI, ingestion, and handlers. Study it to see how the primitives you've learned assemble into a real service.

Its own environment

Uses Poetry (pyproject.toml) and its own example.env. Copy that to .env and fill keys. This is the one folder that is a full app with its own setup.

02 How to study it — trace one request

  1. Read its README.md for the intended setup.
  2. Open ui/main.py — where a user message enters.
  3. Follow to endpoints/chat.py — the request handler.
  4. Into handlers/base.py — streaming/callback handling.
  5. And endpoints/ingest.py — how documents get embedded/stored for retrieval.

✔ Worked answer / expected output

Tracing UI → endpoint → handler → model shows the anatomy of a production RAG service: an ingestion path (documents → vector store) and a query path (message → retrieve → generate → stream back). No new concepts — it's the assembly that matters.

03 When to do this

Last, as a capstone read

Do this after the other three external folders and your own 03 material. It's most valuable as a 'so this is how it all fits into a service' read rather than a first exercise. You may not run it end-to-end without its full stack — reading the structure is the main win.

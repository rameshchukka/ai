L5 Deep Dive — Evaluation

Evaluate a Q&A app at scale: auto-generate test questions, trace a run with debug, and grade answers with an LLM (the RAGAS idea).

01 What this notebook teaches

How to evaluate a Q&A app without hand-checking every answer: auto-generate test questions, run them, and have an LLM grade the results.

Why this matters

Once you have a RAG app (L4), how do you know it's good, and whether a change helped? You need test examples and a way to score answers. Doing that manually doesn't scale — so you enlist LLMs to both create tests and grade them.

03 Getting test data two ways

code

Hard-coded examples (by hand)

examples = [
  {"query": "Do the Cozy Comfort Pullover Set have side pockets?",
   "answer": "Yes"},
  {"query": "...", "answer": "..."}]
  • A couple of question/answer pairs written manually. Fine for a start, but tedious and doesn't scale.
code

LLM-generated examples

from langchain.evaluation.qa import QAGenerateChain
example_gen_chain = QAGenerateChain.from_llm(ChatOpenAI())
new_examples = example_gen_chain.apply_and_parse(
    [{"doc": t} for t in data[:5]])
examples += new_examples
  • QAGenerateChain reads documents and writes Q&A pairs about them automatically.
  • apply_and_parse runs it over several docs and parses the results into example dicts.
  • Now you have a test set with almost no manual effort — combine with the hand-written ones.

04 Evaluating — manual then LLM-assisted

code

See inside a single run with debug

import langchain
langchain.debug = True
qa.run(examples[0]["query"])
langchain.debug = False
  • langchain.debug = True prints every intermediate step — the retrieved docs, the exact prompt, the raw LLM output. Essential for understanding why an answer came out a certain way.
code

LLM-assisted grading

predictions = qa.apply(examples)          # run all test questions
from langchain.evaluation.qa import QAEvalChain
eval_chain = QAEvalChain.from_llm(ChatOpenAI(temperature=0))
graded = eval_chain.evaluate(examples, predictions)
  • qa.apply(examples) gets the app's answer for every test question.
  • QAEvalChain is an LLM that compares each predicted answer to the expected one and outputs CORRECT / INCORRECT — a grader model judging the app.
  • This is the same idea as RAGAS: use a capable LLM as the judge so you don't hand-score everything. Ties directly to your ragas_guide.

05 Takeaways

  • Generate test data with QAGenerateChain (don't hand-write it all).
  • Use langchain.debug=True to see the full trace of one run.
  • Grade at scale with QAEvalChain — LLM-as-judge.
Observe: Caveat worth knowing: an LLM grader isn't perfect — it can mismark. It's a scalable signal, not ground truth. That's exactly why your retrieval_metrics module also does exact, hand-checkable P@K/R@K on labeled data.

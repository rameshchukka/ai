L3 Deep Dive — Chains

Connecting LLM calls: the LLMChain atom, sequential chains that pass data between steps, and a router that dispatches to specialist prompts.

GoalLLMChainSimpleSeqSequentialRouterTakeaways

01 What this notebook teaches

Chains — how to connect LLM calls together so the output of one feeds the next, and how a router can pick which chain to run based on the input.

Why chains

One prompt is rarely a whole task. Chains let you break work into steps (each its own prompt), pass data between them, and even branch — the beginning of real pipelines.

02 LLMChain — the atom

code

A prompt + a model, bundled

from langchain.chains import LLMChain
llm = ChatOpenAI(temperature=0.9)
prompt = ChatPromptTemplate.from_template(
   "What is the best name to describe a company that makes {product}?")
chain = LLMChain(llm=llm, prompt=prompt)
chain.run("Queen Size Sheet Set")
  • LLMChain = one prompt template + one model, callable with .run(input).
  • This is the unit every bigger chain is built from.
  • temperature=0.9 here → more creative/varied names (a naming task wants variety).

03 SimpleSequentialChain — one output → next input

code

Two chains in a line

from langchain.chains import SimpleSequentialChain
chain_one = LLMChain(llm=llm, prompt=first_prompt)   # product -> company name
chain_two = LLMChain(llm=llm, prompt=second_prompt)  # name -> description
overall = SimpleSequentialChain(chains=[chain_one, chain_two], verbose=True)
overall.run(product)
  • The single output of chain_one becomes the single input of chain_two.
  • 'Simple' = exactly one string in, one string out, at each step.
  • verbose=True prints each intermediate result — watch the company name appear, then its description.

04 SequentialChain — multiple named variables

code

Threading several inputs/outputs by name

from langchain.chains import SequentialChain
chain_two = LLMChain(llm=llm, prompt=second_prompt, output_key="summary")
chain_three = LLMChain(..., output_key="language")
overall_chain = SequentialChain(
   chains=[chain_one, chain_two, chain_three, chain_four],
   input_variables=["Review"],
   output_variables=["English_Review","summary","followup_message"])
  • When steps need more than one named value, you use output_key on each chain and declare the overall input_variables/output_variables.
  • Example flow: translate a review → summarize it → detect its language → write a follow-up in that language. Each step's named outputs are available to later steps.
  • This is how you build a real multi-step pipeline with data flowing by name.

05 Router Chain — pick the right sub-chain

code

Route the input to a specialist prompt

from langchain.chains.router import MultiPromptChain
from langchain.chains.router.llm_router import LLMRouterChain, RouterOutputParser
# prompt_infos = [physics, math, history, computer science] each with a template
chain = MultiPromptChain(router_chain=router_chain,
                         destination_chains=destination_chains,
                         default_chain=default_chain, verbose=True)
chain.run("What is black body radiation?")
  • An LLM router reads the input and decides which specialist prompt should handle it.
  • 'black body radiation' → physics chain; '2+2' → math chain; a DNA question → the default/biology path. With verbose=True you see the chosen destination printed.
  • The router itself is just an LLMChain whose job is classification — LLMs routing to LLMs.
  • The MULTI_PROMPT_ROUTER_TEMPLATE instructs the router to return JSON naming the destination; RouterOutputParser reads that choice.

06 Takeaways

  • LLMChain: the atom (prompt + model).
  • SimpleSequentialChain: single value passed down a line.
  • SequentialChain: multiple named values threaded through steps.
  • MultiPromptChain (router): classify the input, dispatch to a specialist.

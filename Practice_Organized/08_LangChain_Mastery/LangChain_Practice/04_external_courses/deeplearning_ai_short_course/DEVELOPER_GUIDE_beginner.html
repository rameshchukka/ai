00 Read this first — what you're about to do

This guide takes you from a blank laptop to completing all six notebooks (L1–L6) of the DeepLearning.AI LangChain course. No prior Python-environment experience assumed. Follow it top to bottom the first time.

The single most important thing to know

These notebooks were written for an old version of LangChain (0.0.x) and an old OpenAI library. If you install the newest versions and run the notebooks as-is, they will error on the very first import. This guide gives you two ways to fix that — a beginner-friendly 'pin the old versions' route (recommended) and a 'modernize the code' route. Pick one and the course just works.

01 Step 1 — Install Python

Check if you already have it

python3 --version

If it prints 3.10, 3.11, or 3.12, you're set. If not, or the command isn't found:

macOS

Install from python.org/downloads (get 3.12), or with Homebrew: brew install python@3.12.

Windows

Install from python.org/downloads. On the first installer screen, tick 'Add python.exe to PATH' — this saves a lot of pain. Then open a fresh Command Prompt and check python --version.

Why 3.10–3.12 and not the newest

The very newest Python (3.13+) sometimes lacks pre-built packages, causing confusing install errors for beginners. 3.12 is the safe choice for this course.

02 Step 2 — Make a virtual environment (a private sandbox)

What a venv is, in one sentence

A virtual environment is a private folder of Python packages for one project, so installing things here can't break other projects or your system Python. You 'activate' it to use it.

macOS / Linux

cd path/to/deeplearning_ai_short_course
python3 -m venv venv
source venv/bin/activate

Windows (Command Prompt)

cd path\to\deeplearning_ai_short_course
python -m venv venv
venv\Scripts\activate

After activating, your prompt shows (venv) at the start. That means it's on. Run deactivate to turn it off; re-run the activate line each new session.

Observe: You only create the venv once (the -m venv line). You activate it every time you open a new terminal to work on the course.

03 Step 3 — Install the libraries (the version that works)

Use these pinned versions — this is the beginner shortcut

With (venv) active, install the older versions the notebooks were built for. This is the least-effort way to make the course run exactly as written:

pip install "langchain==0.0.312" "openai==0.28.1" \
  python-dotenv tiktoken \
  docarray pandas jupyter

Then confirm it worked:

python -c "import langchain, openai; print('ok', langchain.__version__, openai.__version__)"

✔ Worked answer / expected output

You should see ok 0.0.312 0.28.1. If so, every notebook's imports (from langchain.chat_models import ChatOpenAI, openai.ChatCompletion.create) will work as written — no code edits needed.

Why pin instead of newest?

In current LangChain the imports moved (e.g. langchain_openai) and in current OpenAI the call changed (client.chat.completions.create). A beginner shouldn't have to rewrite the course to run it. Section 08 shows the modern equivalents for when you're ready.

04 Step 4 — Get an OpenAI API key and store it safely

  1. Create an account at platform.openai.com and add a little billing credit (these notebooks cost cents to run).
  2. Go to API keys → Create new secret key → copy it (you only see it once).
  3. In the course folder, create a file named exactly .env with this one line:
    OPENAI_API_KEY=sk-your-key-here
  4. Create a .gitignore file containing .env so you never commit the key.

Never share or commit your key

Treat the key like a password. The notebooks read it from .env via load_dotenv() — you never paste it into the code. If a key ever leaks, revoke it on the OpenAI dashboard and make a new one.

On your work laptop

If your organization blocks OpenAI, run this course on a personal laptop/network — or, once comfortable, point the notebooks at your in-house model wrapper (the LangChain interface is the same). For learning, a personal OpenAI key is simplest.

05 Step 5 — Open the notebooks

Option A — Jupyter in the browser

# with (venv) active, in the course folder:
jupyter notebook

A browser tab opens listing the L1…L6 files. Click L1-Model_prompt_parser.ipynb.

Option B — VS Code (nicer)

Install VS Code + the Python and Jupyter extensions. Open the course folder, open the .ipynb, and in the top-right kernel picker choose your venv. Run a cell with Shift+Enter.

Observe: Run cells one at a time, top to bottom, reading the output of each before moving on. If you run cells out of order you'll get 'name not defined' errors — start again from the top.

06 Step 6 — Work the six lessons (what each teaches + what to expect)

L1

Models, Prompts & Output Parsers

The difference between calling the model raw vs through LangChain's ChatModel + PromptTemplate, and using an output parser to get structured fields.

✔ Worked answer / expected output

You extract structured info (e.g. gift/sentiment fields) from a product review and get back a Python dict, not just text. First lesson where 'templates + parser' clicks.

L2

Memory

Four ways a chatbot can 'remember' earlier turns: full buffer, last-k window, token budget, and summary.

✔ Worked answer / expected output

With buffer memory the bot recalls your name from earlier; with window/summary memory it deliberately forgets older turns to save tokens. You see the trade-off directly.

L3

Chains

Composing steps: LLMChain, sequential chains (output → next input), and a router that picks a sub-chain by topic.

✔ Worked answer / expected output

The router sends a physics question to the physics prompt and a math one to the math prompt, printing which it chose. The images/ diagrams illustrate each chain type.

L4

Q&A over Documents (RAG)

Retrieval-augmented generation over the included clothing-catalog CSV — load, embed, retrieve, answer.

✔ Worked answer / expected output

You ask about products and get an answer grounded in specific catalog rows, often as a markdown table. This is the course's RAG lesson — the framework version of retrieve-then-generate.

L5

Evaluation

Auto-generate test questions and have an LLM grade the app's answers.

✔ Worked answer / expected output

Prints per-example CORRECT/INCORRECT judgments from an LLM grader — the idea behind RAGAS-style evaluation, in miniature.

L6

Agents

An agent that uses tools (calculator, Wikipedia, a Python REPL), then you add your own tool.

✔ Worked answer / expected output

With verbose output on, you watch the agent reason and choose tools — e.g. using the calculator for arithmetic. Your first look at tool-using agents.

07 Step 7 — When something breaks (beginner troubleshooting)

Error you seeWhat it means & the fix
ModuleNotFoundError: langchainvenv not active or install skipped. Activate the venv, re-run the Step-3 pip line.
ImportError: cannot import name ChatOpenAI from langchain.chat_modelsYou installed a new LangChain. Either pin to 0.0.312 (Step 3) or use the modern imports in Section 08.
openai.ChatCompletion ... no longer supported / APIRemovedInV1You have openai ≥1.0. Pin openai==0.28.1 (Step 3), or modernize (Section 08).
AuthenticationError / 401Key missing/wrong. Check .env has OPENAI_API_KEY=sk-... and that you called load_dotenv().
RateLimitError / quotaNo billing credit on the OpenAI account, or too many calls. Add a little credit; wait a moment.
name '...' is not definedYou ran cells out of order. Re-run from the top of the notebook.
Jupyter uses the wrong PythonThe kernel isn't your venv. In VS Code pick the venv kernel; in Jupyter, install it: python -m ipykernel install --user --name venv then select it.

08 Optional — running on current LangChain (the 'modern' route)

Only do this if you'd rather use up-to-date libraries

The pinned versions in Step 3 are the easy path. If you want the newest LangChain/OpenAI, install these and make the small edits below in each notebook.

pip install langchain langchain-openai langchain-community openai python-dotenv tiktoken docarray pandas jupyter

The find-and-replace you'll do

Old (in the notebooks)New (modern)

Observe: Most other LangChain imports (prompts, chains, memory) still work or have near-identical new paths. If one errors, search the current LangChain docs for the class name — the concept is unchanged, only the module moved.

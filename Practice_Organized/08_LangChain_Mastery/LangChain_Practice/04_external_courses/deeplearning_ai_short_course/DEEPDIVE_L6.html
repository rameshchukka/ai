01 What this notebook teaches

Agents — giving an LLM tools and letting it decide which to call to answer a question. Built-in tools, a Python-execution agent, and defining your own tool.

What an 'agent' is

An agent is a loop: the LLM thinks, picks a tool, sees the tool's result, and repeats until it can answer. It turns a text-only model into something that can calculate, look things up, or run code — by reasoning about which tool fits.

02 Built-in tools

code

Load tools and initialize an agent

from langchain.agents import load_tools, initialize_agent, AgentType
llm = ChatOpenAI(temperature=0)
tools = load_tools(["llm-math", "wikipedia"], llm=llm)
agent = initialize_agent(tools, llm,
    agent=AgentType.CHAT_ZERO_SHOT_REACT_DESCRIPTION,
    handle_parsing_errors=True, verbose=True)
agent("What is the 25% of 300?")
  • load_tools grabs ready-made tools: llm-math (a calculator) and wikipedia (lookup).
  • AgentType.CHAT_ZERO_SHOT_REACT_DESCRIPTION = the ReAct strategy: the model reasons in Thought/Action/Observation steps and picks tools from their text descriptions.
  • handle_parsing_errors=True lets the agent recover if the LLM mis-formats a step.
  • For '25% of 300' the agent chooses the math tool and returns 75 — with verbose=True you watch it reason and call the tool.
code

A lookup question

question = "Tom M. Mitchell ... what book did he write?"
agent(question)
  • Here the agent chooses the Wikipedia tool instead — same loop, different tool, chosen by reasoning about the question.

03 Python agent — the LLM writes & runs code

code

An agent whose tool is a Python REPL

from langchain.agents.agent_toolkits import create_python_agent
from langchain.tools.python.tool import PythonREPLTool
agent = create_python_agent(llm, tool=PythonREPLTool(), verbose=True)
agent.run(f"Sort these customers by last then first name and print: {customer_list}")
  • The tool is a real Python interpreter. The agent writes code, runs it, sees the output, and returns the result.
  • For the sort task it emits a sorted(...) call with the right key and executes it.
  • Turn on langchain.debug=True to see the exact code it generated — instructive and a little uncanny.

04 Define your own tool

code

The @tool decorator

from langchain.agents import tool
from datetime import date
@tool
def time(text: str) -> str:
    """Returns todays date, use for any questions about today's date...."""
    return str(date.today())
agent = initialize_agent(tools + [time], llm, ...)
agent("whats the date today?")
  • @tool turns any Python function into a tool the agent can choose.
  • The docstring is critical — the agent reads it to decide when this tool applies. A vague docstring → the agent won't know to use it.
  • Asked the date, the agent routes to your time tool and returns today's date. This is how you extend an agent with your own capabilities (an internal API, a DB lookup, etc.).

05 Takeaways

  • An agent = LLM + tools + a reasoning loop (ReAct) that picks tools.
  • load_tools for built-ins; create_python_agent to run code; @tool for your own.
  • Tool descriptions/docstrings are how the agent decides — write them well.

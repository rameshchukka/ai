5 Levels of Summarization — Novice to Expert

# Level 1: summarize a sentence     -> a basic prompt
# Level 2: a paragraph              -> prompt + more instruction
# Level 3: a page                   -> map_reduce over chunks
# Level 4: a book                   -> chunk + cluster + summarize representatives
# Level 5: an unbounded corpus      -> agents + retrieval
  • A masterclass in scaling ONE task as input size grows — the single best notebook for building real intuition about context limits and map-reduce.
  • Level 4's 'embed → cluster → summarize the representative chunk of each cluster' trick is a genuinely clever pattern worth stealing.
walkthrough

Ask A Book Questions — top-k similarity search

chunks = splitter.split_documents(book_docs)
db = Pinecone.from_documents(chunks, embeddings, index_name=...)
qa = RetrievalQA.from_chain_type(llm, retriever=db.as_retriever())
qa.run("What is the main argument of chapter 3?")
  • The clearest end-to-end RAG-over-a-book recipe — load, chunk, embed, retrieve, answer.
  • Swap Pinecone for Chroma/FAISS to run it fully local (Pinecone needs a cloud account).
walkthrough

Advanced Retrieval With LangChain + Retrieval_With_MMR

# MMR = Maximal Marginal Relevance: retrieve results that are relevant
# AND diverse, so you don't get 5 near-identical chunks
retriever = db.as_retriever(search_type="mmr", search_kwargs={"k":5, "fetch_k":20})
  • MMR fixes a real problem: plain top-k often returns near-duplicate chunks. MMR trades a little relevance for diversity, giving broader context.
  • Ties directly to the near-duplicate issue you diagnose in Chroma Studio.

04 Two threads worth following

Structured output, three ways

The cookbook shows extraction via (1) prompt+parser, (2) function calling (the modern reliable way), and (3) Kor (a dedicated extraction library). Do all three back to back to see the trade-offs — this is a genuinely important skill for turning an LLM into a dependable pipeline component.

Retrieval quality

'Ask A Book' → 'Advanced Retrieval' → 'MMR' is a progression from basic RAG to better retrieval. It reinforces exactly what your RAG_Course advanced module covered (reranking, diversity) — here as applied recipes.

05 Running the recipes

Setup

Base install + per-recipe extras (the notebook tops list them). Common ones: faiss-cpu/chromadb/pinecone-client for vector stores, kor for the Kor recipe, tiktoken for token counting. Data is in data/ (Paul Graham essays, CSVs).

practice Start with the three headline recipes (Summarization, Ask A Book, MMR). Then pick recipes that match your real tasks — extraction and email generation transfer especially well to business use. Swap any cloud vector store for local Chroma to stay offline.

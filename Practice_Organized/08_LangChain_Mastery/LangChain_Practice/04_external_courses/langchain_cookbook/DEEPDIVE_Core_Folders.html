02 chains/Chain Types — the document-combining strategies

walkthrough

The four ways to feed many documents to an LLM

# when retrieved docs don't all fit in one prompt, pick a strategy:
RetrievalQA.from_chain_type(llm, chain_type="stuff")      # cram all into one prompt
                                     "map_reduce"          # summarize each, then combine
                                     "refine"              # iterate, refining the answer
                                     "map_rerank"          # score each, take the best
  • stuff: simplest, but fails if the docs exceed the context window.
  • map_reduce: summarize each doc separately, then merge — scales to many docs.
  • refine: build the answer doc-by-doc, refining as it goes — good quality, more LLM calls.
  • map_rerank: score each doc's answer, return the highest. Knowing which to pick is a real RAG skill.

03 agents/ — tools and the ReAct loop

walkthrough

An agent choosing tools

tools = load_tools(["llm-math", "wikipedia"], llm=llm)
agent = initialize_agent(tools, llm,
          agent="zero-shot-react-description", verbose=True)
agent.run("Who is Olivia Wilde's boyfriend? What is his age raised to the 0.23 power?")
  • The agent reasons (Thought), picks a tool (Action), reads the result (Observation), and loops — the ReAct pattern.
  • verbose=True prints the whole loop; watch it choose Wikipedia then the calculator.
  • The Zapier notebook extends this to real actions (send email, create doc) across thousands of apps — agents that do things, not just answer.
  • This is the same agent concept as your other deep-dives — here with a fun multi-tool example.

04 loaders/ — getting real documents in

walkthrough

YouTube and Google Drive loaders

from langchain.document_loaders import YoutubeLoader
loader = YoutubeLoader.from_youtube_url("https://youtu.be/...", add_video_info=True)
transcript_docs = loader.load()     # the video transcript as Documents
  • Loaders turn external sources (YouTube transcripts, Drive files, PDFs, web pages) into Document objects your RAG pipeline can chunk and embed.
  • The variety of loaders is a big part of LangChain's value — you rarely write parsing code.
  • Try the YouTube loader on a talk, then feed the transcript into the Part 1 RAG loop and ask it questions.

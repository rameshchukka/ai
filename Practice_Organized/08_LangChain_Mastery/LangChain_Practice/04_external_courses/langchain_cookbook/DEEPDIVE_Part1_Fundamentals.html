01 What Part 1 covers

The single best starting notebook in the whole cookbook: a hands-on tour of every LangChain building block. Think of it as a runnable glossary — when a term is fuzzy, run its cell here.

The 6 component families

LangChain organizes into: Schema (the data types), Models (the AI), Prompts (instructions), Indexes (your documents), Memory (conversation state), Chains & Agents (composition). Part 1 walks each in order.

02 Schema — the data types

walkthrough

Text, ChatMessages, Documents

from langchain.schema import HumanMessage, SystemMessage, AIMessage
from langchain.schema import Document

msgs = [SystemMessage(content="You are a helpful assistant."),
        HumanMessage(content="What is the capital of France?")]
doc = Document(page_content="LangChain is a framework.",
               metadata={"source": "notes"})
  • Text is just a string prompt. ChatMessages carry a role (System/Human/AI) — chat models need these, not bare strings.
  • Document = page_content + metadata. Everything you load/split/retrieve is a Document. This is the unit RAG moves around.

03 Models — the AI interface

walkthrough

LLM, Chat, Embedding, Function-calling

from langchain.llms import OpenAI
from langchain.chat_models import ChatOpenAI
from langchain.embeddings import OpenAIEmbeddings

llm  = OpenAI(model_name="text-davinci-003")     # text in -> text out
chat = ChatOpenAI()                               # messages in -> message out
emb  = OpenAIEmbeddings()                          # text in -> vector out
vector = emb.embed_query("hello")                 # a list of floats
  • Three model types you'll use everywhere: LLM (legacy text completion), Chat (the modern default), Embedding (powers search/RAG).
  • Function-calling models return structured arguments, not prose — the foundation for reliable extraction (see the applied recipes guide).
  • (These are old langchain.* imports; current LangChain uses langchain_openai. Concept identical — see the version note in the README.)

04 Prompts — instructions to the model

walkthrough

PromptTemplate, ExampleSelectors, OutputParsers

from langchain import PromptTemplate
template = PromptTemplate(
    input_variables=["product"],
    template="What is a good name for a company that makes {product}?")
template.format(product="shoes")
  • PromptTemplate = reusable prompt with named slots (validated).
  • ExampleSelectors pick which few-shot examples to include (e.g. the most similar ones) so the prompt stays small but relevant.
  • OutputParsers turn the reply into structure — the notebook shows two ways: prompt-instructions+string-parsing, and OpenAI functions (the robust way).

05 Indexes — making documents searchable (this is RAG)

walkthrough

Loaders → Splitters → VectorStores → Retrievers

from langchain.document_loaders import TextLoader
from langchain.text_splitter import RecursiveCharacterTextSplitter
from langchain.vectorstores import FAISS

docs   = TextLoader("data/PaulGrahamEssaySmall/disc.txt").load()
chunks = RecursiveCharacterTextSplitter(chunk_size=500).split_documents(docs)
db     = FAISS.from_documents(chunks, OpenAIEmbeddings())
retriever = db.as_retriever()
hits = retriever.get_relevant_documents("what is discipline?")
  • This is the entire RAG ingestion + retrieval loop in five lines: load → split → embed+store → retrieve.
  • It uses the included Paul Graham essays as the corpus — real documents to practice on.
  • Everything you learned in RAG_Course part 1 is exactly this, now via LangChain's objects.

06 Memory, Chains & Agents

walkthrough

ChatMessageHistory, SimpleSequentialChain, an Agent

from langchain.chains import SimpleSequentialChain, LLMChain
# chain: output of step 1 becomes input of step 2
overall = SimpleSequentialChain(chains=[chain_one, chain_two], verbose=True)

from langchain.agents import load_tools, initialize_agent
tools = load_tools(["llm-math"], llm=llm)
agent = initialize_agent(tools, llm, agent="zero-shot-react-description")
  • Memory stores conversation turns so a bot remembers context.
  • Chains connect steps (output→input). Agents let the model choose tools in a reasoning loop.
  • These are the same concepts covered in depth in your other course deep-dives — here they're one cell each, so it's the fastest way to see them all working.

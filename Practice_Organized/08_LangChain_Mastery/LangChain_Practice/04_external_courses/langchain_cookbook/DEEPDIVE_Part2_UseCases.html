02 Summarization — short vs long text

walkthrough

The length problem, and map-reduce

# short text: just ask
chain = load_summarize_chain(llm, chain_type="stuff")
# long text: split, summarize pieces, combine
chain = load_summarize_chain(llm, chain_type="map_reduce")
chain.run(split_documents)
  • Short text fits in one prompt (stuff). Long text doesn't — so you map_reduce: summarize each chunk, then summarize the summaries.
  • This directly motivates the 5 Levels of Summarization recipe (next guide).

03 Q&A using documents as context (RAG)

walkthrough

Simple Q&A, then with embeddings

# retrieve relevant chunks, stuff into the prompt, answer
qa = RetrievalQA.from_chain_type(llm=llm, chain_type="stuff",
        retriever=vectorstore.as_retriever())
qa.run("What did the author do growing up?")
  • The canonical RAG use case: embed docs, retrieve by question, answer from the retrieved context.
  • Part 2 shows both a naive version and the embeddings-backed version — the same progression you saw from scratch in your RAG_Course.

04 Extraction — turning text into structured data

walkthrough

Vanilla vs Response Schema

from langchain.output_parsers import StructuredOutputParser, ResponseSchema
schemas = [ResponseSchema(name="name", description="the person's name"),
           ResponseSchema(name="age",  description="their age as an integer")]
parser = StructuredOutputParser.from_response_schemas(schemas)
  • Extraction pulls fields (names, dates, amounts) out of free text into JSON — one of the highest-value LLM tasks in business.
  • The Response Schema approach declares the fields you want; the parser reads them back reliably. The applied recipes go further with function-calling and Kor.

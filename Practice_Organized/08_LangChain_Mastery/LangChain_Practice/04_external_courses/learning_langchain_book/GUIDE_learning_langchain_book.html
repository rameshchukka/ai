01 About this code

Code for the Learning LangChain book — 10 chapters, each with a py/ and a js/ version. Use py/. The most comprehensive material in the bundle; it moves from basics to production RAG, agents (LangGraph), and evaluation.

How to work it

Each chapter's py/ folder has several small lettered files (a-*.py, b-*.py, …) meant to be run in alphabetical order — each adds one idea. Run them in order; read before running.

03 Recommended path + worked outcomes

start

ch1 → ch2 → ch3 (the core arc)

✔ Worked answer / expected output

ch1: you confirm each model/prompt primitive works in isolation. ch2: you build the ingestion pipeline (load→split→embed) and can inspect chunk counts and vector shapes. ch3: a-basic-rag.py answers from retrieved context, then each later file measurably improves retrieval — e.g. multi-query casts a wider net, HyDE embeds a hypothetical answer, self-query extracts metadata filters from the question. Run them on the same query and compare which retrieves best.

then

ch5–ch10 (agents → graphs → evaluation)

✔ Worked answer / expected output

You progress from a single tool-using agent to LangGraph state machines that branch and loop, and finally to grading agent outputs (ch10) — the same evaluate→improve loop as your RAGAS/metrics modules, applied to agents.

04 Notes

py only; providers may need adapting

Ignore the js/ folders unless you want JavaScript. Files default to cloud providers — swap the model line for your in-house wrapper where the org network blocks them.

01 Chapter 10 — Evaluation of RAG & SQL agents

Close the loop: build datasets, run RAG and SQL agents against them, and grade the results — the measure→improve discipline applied to agents.

Why this is the capstone

Everything before builds capability; this chapter measures it. You create evaluation datasets, run agent graphs, and score correctness — the same philosophy as your RAGAS and retrieval_metrics modules, applied to full agents.

04 Running

Needs LangSmith

These use LangSmith for datasets + evaluation. Set LANGSMITH_API_KEY (and LANGCHAIN_TRACING_V2=true). On the org network LangSmith may be blocked — run from a personal environment, or adapt the scoring to your own offline metrics (your retrieval_metrics module already does exact P@K/R@K without any external service).

05 Takeaways

  • Evaluation = dataset + run the agent + score with evaluators.
  • Grades correctness/groundedness/relevance — the RAGAS ideas, at agent level.
  • This closes the loop: build (ch1–9) → measure (ch10) → improve.
Observe: You've now seen evaluation three ways: RAGAS (LLM-judged), retrieval_metrics (exact, labeled), and here (agent-level via LangSmith). An expert reaches for whichever fits the question.

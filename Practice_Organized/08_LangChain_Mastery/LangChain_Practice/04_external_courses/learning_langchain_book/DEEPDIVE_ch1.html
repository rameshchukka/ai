03 The key ideas, in both languages

a-llm — the simplest call

Python

from langchain_openai.chat_models import ChatOpenAI
model = ChatOpenAI(model="gpt-3.5-turbo")
response = model.invoke("The sky is")
print(response.content)

JavaScript / TypeScript

import { ChatOpenAI } from '@langchain/openai';
const model = new ChatOpenAI({ model: 'gpt-3.5-turbo' });
const response = await model.invoke('The sky is');
console.log(response);
  • .invoke(input) is the universal 'run it once' method — same name in both languages.
  • Python returns an object with .content; JS returns the message object (log it to see .content).
  • JS is async — note await. Every LangChain call in JS is awaited.
h-structured — typed output

Python

from pydantic import BaseModel
class Answer(BaseModel):
    setup: str; punchline: str
model.with_structured_output(Answer).invoke("Tell me a joke")

JavaScript / TypeScript

import { z } from 'zod';
const schema = z.object({ setup: z.string(), punchline: z.string() });
await model.withStructuredOutput(schema).invoke('Tell me a joke');
  • Structured output guarantees the model returns fields you defined, as an object — no manual parsing (the robust version of L1's output parser from the DL.AI course).
  • Python uses Pydantic; JS uses Zod — same idea (a schema), different library.
k vs l — imperative vs declarative (LCEL)

Python

# imperative: call each step yourself
prompt_value = prompt.invoke({"topic": "cats"})
message = model.invoke(prompt_value)

# declarative (LCEL): pipe them
chain = prompt | model | StrOutputParser()
chain.invoke({"topic": "cats"})

JavaScript / TypeScript

// declarative with .pipe()
const chain = prompt.pipe(model).pipe(new StringOutputParser());
await chain.invoke({ topic: 'cats' });
  • Imperative = call each piece by hand (clear, verbose). Declarative / LCEL = compose with | (Python) or .pipe() (JS) into one runnable chain.
  • LCEL chains get streaming, batching, and async for free — this is the modern LangChain style you'll see throughout the rest of the book.

04 Running

Running either language

Python: pip install langchain langchain-openai langchain-community langchain-postgres langgraph python-dotenv, then python ch1/py/a-llm.py. JS: npm install @langchain/openai @langchain/core @langchain/community @langchain/langgraph dotenv, then npx tsx ch1/js/a-llm.js (or node). Both read your key from .env (OPENAI_API_KEY). The two languages mirror each other — same concepts, idiomatic syntax.

05 Takeaways

  • .invoke/.batch/.stream are the universal run methods.
  • Prompt templates + structured output = reliable, reusable prompting.
  • LCEL (| / .pipe()) is how you compose — learn it here, it's everywhere later.

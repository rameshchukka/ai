01 Chapter 3 — RAG & advanced retrieval

Basic RAG, then a series of retrieval upgrades — each file improves how you find the right context before generating.

Each file is one retrieval technique

Start with a-basic-rag, then each later file swaps in a smarter retrieval strategy. Run the same question through several and compare what gets retrieved — that's the exercise.

02 The techniques (a → i)

03 The baseline and one upgrade, in both languages

a-basic-rag — the @chain retriever + generate

Python

from langchain_core.runnables import chain
@chain
def retriever(query: str):
    return db.similarity_search(query, k=4)

prompt = ChatPromptTemplate.from_template(
   "Answer using ONLY this context:\n{context}\n\nQuestion: {question}")
# retrieve, format, prompt, model -> answer

JavaScript / TypeScript

const retriever = vectorStore.asRetriever({ k: 4 });
// RunnableSequence: retrieve -> format -> prompt -> model
  • @chain (Python) turns a function into a runnable you can pipe. JS uses RunnableSequence / .asRetriever().
  • The prompt says 'answer using ONLY this context' — grounding the model to prevent hallucination, the core RAG discipline.
c-multi-query — cast a wider net

Python

# generate N reworded queries with the LLM, search each, union hits
from langchain.retrievers.multi_query import MultiQueryRetriever
retriever = MultiQueryRetriever.from_llm(db.as_retriever(), llm)

JavaScript / TypeScript

import { MultiQueryRetriever } from 'langchain/retrievers/multi_query';
const retriever = MultiQueryRetriever.fromLLM({ retriever, llm });
  • The LLM rewrites the question several ways; each is searched; results are unioned — catches documents a single phrasing would miss.
  • This directly improves recall — the metric from your retrieval_metrics module.

04 Running

Running either language

Python: pip install langchain langchain-openai langchain-community langchain-postgres langgraph python-dotenv, then python ch1/py/a-llm.py. JS: npm install @langchain/openai @langchain/core @langchain/community @langchain/langgraph dotenv, then npx tsx ch1/js/a-llm.js (or node). Both read your key from .env (OPENAI_API_KEY). The two languages mirror each other — same concepts, idiomatic syntax.

05 Takeaways

  • Basic RAG is the baseline; the other files are retrieval upgrades.
  • multi-query/fusion boost recall; HyDE helps vague queries; self-query adds metadata filters; routers pick the right source.
  • Compare them on one question and measure with P@K/R@K — ties to your metrics work.

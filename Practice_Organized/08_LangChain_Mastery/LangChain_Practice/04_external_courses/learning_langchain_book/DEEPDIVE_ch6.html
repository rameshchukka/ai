01 Chapter 6 — Agents (LangGraph)

Build a tool-using agent as a LangGraph: the model decides whether to call a tool, the tool runs, the result feeds back, and it loops until done.

An agent = a graph with a loop

The model node emits either a final answer or a tool call. A conditional edge routes tool calls to a tool node, whose output goes back to the model. That cycle is the agent.

03 The basic agent, in both languages

a-basic-agent — bind tools + graph loop

Python

@tool
def calculator(query: str) -> str:
    """A simple calculator. Input is a math expression."""
    return ast.literal_eval(query)
search = DuckDuckGoSearchRun()
tools = [search, calculator]
model = ChatOpenAI(temperature=0.1).bind_tools(tools)

builder = StateGraph(State)
builder.add_node("model", model_node)
builder.add_node("tools", ToolNode(tools))
builder.add_conditional_edges("model", tools_condition)
builder.add_edge("tools", "model")

JavaScript / TypeScript

const model = new ChatOpenAI({ temperature: 0.1 }).bindTools(tools);
// StateGraph with 'model' + ToolNode('tools'),
// conditional edge model->tools, edge tools->model
  • .bind_tools(tools) tells the model which tools exist (it reads their names + docstrings to decide when to use them).
  • ToolNode runs whatever tool the model asked for; tools_condition is the conditional edge that routes to tools only if the model requested one.
  • tools → model edge closes the loop: the tool result goes back for the model to continue. That cycle is the whole agent.
  • The docstring on each @tool is how the model chooses — write it clearly.

04 Running

Running either language

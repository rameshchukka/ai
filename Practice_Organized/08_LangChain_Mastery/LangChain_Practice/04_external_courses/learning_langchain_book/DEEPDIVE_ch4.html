01 Chapter 4 — Memory & state with LangGraph

Conversation memory done the modern way — with LangGraph state, persistence, and message trimming/filtering.

LangGraph enters here

The book moves from simple memory to LangGraph — a way to build stateful, multi-step apps as a graph of nodes. State (including message history) flows through the graph and can be persisted. This is the foundation for the agents in ch6–ch9.

03 State graph + persistence, in both languages

b — a minimal StateGraph

Python

from langgraph.graph import StateGraph, START
from langgraph.graph.message import add_messages
from typing import Annotated, TypedDict
class State(TypedDict):
    messages: Annotated[list, add_messages]
builder = StateGraph(State)
builder.add_node("model", model_node)
builder.add_edge(START, "model")
graph = builder.compile()

JavaScript / TypeScript

import { StateGraph, START } from '@langchain/langgraph';
const graph = new StateGraph(State)
  .addNode('model', modelNode)
  .addEdge(START, 'model').compile();
  • State is a typed dict; add_messages is a reducer that appends new messages to history automatically.
  • You define nodes (steps) and edges (flow) and compile() into a runnable graph — the LangGraph mental model.
  • JS mirrors this with a fluent builder.
c — persistence via a checkpointer

Python

from langgraph.checkpoint.memory import MemorySaver
graph = builder.compile(checkpointer=MemorySaver())
graph.invoke(input, {"configurable": {"thread_id": "1"}})

JavaScript / TypeScript

import { MemorySaver } from '@langchain/langgraph';
const graph = builder.compile({ checkpointer: new MemorySaver() });
  • A checkpointer saves graph state keyed by a thread_id, so the same conversation can resume later — durable memory.
  • Swap MemorySaver for a DB-backed saver in production.

04 Running

Running either language

Python: pip install langchain langchain-openai langchain-community langchain-postgres langgraph python-dotenv, then python ch1/py/a-llm.py. JS: npm install @langchain/openai @langchain/core @langchain/community @langchain/langgraph dotenv, then npx tsx ch1/js/a-llm.js (or node). Both read your key from .env (OPENAI_API_KEY). The two languages mirror each other — same concepts, idiomatic syntax.

05 Takeaways

  • LangGraph models an app as nodes + edges over a typed State.
  • add_messages gives you conversation memory for free.
  • A checkpointer + thread_id = persistent, resumable conversations.

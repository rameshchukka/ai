01 Chapter 8 — Agent UX (control & human-in-the-loop)

Making agents usable and safe: structured/streaming output, interrupting for human approval, authorization, resuming, editing state, and forking.

Production agents need control

A raw agent loop isn't enough for real use — you need to stream progress, pause for a human to approve an action, resume where you left off, and sometimes edit the agent's state. This chapter is those controls.

03 Human-in-the-loop, in both languages

c-interrupt — pause for approval

Python

graph = builder.compile(checkpointer=saver,
                        interrupt_before=["tools"])
# run pauses before executing a tool; a human inspects,
# then graph.invoke(None, config) resumes it

JavaScript / TypeScript

const graph = builder.compile({ checkpointer,
  interruptBefore: ['tools'] });
  • interrupt_before=["tools"] pauses the graph right before a tool runs, so a human can approve or reject — essential when tools do real actions (payments, emails).
  • Because state is checkpointed (ch4), the run resumes exactly where it paused.

04 Running

Running either language

Python: install langgraph langchain-openai langchain-community, run python chN/py/x.py. JS: npm i @langchain/langgraph @langchain/openai @langchain/community, run npx tsx chN/js/x.js. Both read OPENAI_API_KEY from .env. Some files also use a search tool (DuckDuckGo) that needs network access.

05 Takeaways

  • Streaming + structured output make agents feel responsive and usable.
  • Interrupt/resume = human-in-the-loop approval, built on checkpointing.
  • Authorize/edit/fork give the control real deployments require.

📘 Concept Notes

A single neuron

A neuron computes a weighted sum of its inputs, adds a bias, then applies a nonlinear activation function. Stack many neurons into a layer, and many layers into a network.

Why nonlinearity matters

Without an activation function between layers, stacking linear layers collapses mathematically into one linear layer — the network gains no extra representational power. ReLU/sigmoid/tanh are what give depth its value.

Matrix form

A whole layer's forward pass is a single matrix multiplication (`X @ W + b`) followed by an elementwise activation — this is why GPUs make forward passes fast: matrix multiplication parallelizes extremely well.

💡 Tips & Pitfalls

Tips

  • ReLU is the default hidden-layer activation for most modern networks.
  • Use sigmoid only on a final binary-classification output; softmax for multiclass; nothing (linear) for regression.
  • Track tensor shape through every layer on paper before coding.

Common Pitfalls

  • Forgetting an activation function between layers, collapsing the network to one linear layer.
  • Mismatched input/output feature dimensions between consecutive layers.

🌍 Real-World Use Cases

📘 Concept Notes

The chain rule, intuitively

Backprop asks: 'how much did this weight contribute to the final error?' It answers this by multiplying local derivatives together, layer by layer, working backward from the loss — that multiplication chain is the chain rule.

Loss functions

MSE (mean squared error) is standard for regression; cross-entropy is standard for classification. Using the wrong one for the task is a common and subtle bug.

Vanishing/exploding gradients

In deep networks, repeatedly multiplying small (or large) derivatives through many layers can make gradients shrink toward zero or blow up — this is why activation choice and network depth interact with training stability.

Autograd automates this

PyTorch's `.backward()` performs exactly the chain-rule computation you do by hand here, automatically, for arbitrarily complex computation graphs.

💡 Tips & Pitfalls

Tips

  • If loss becomes NaN, suspect learning rate too high or exploding gradients.
  • If loss barely moves, suspect learning rate too low, vanishing gradients, or a label/loss mismatch.
  • Plot the training loss curve every time — it's the single most informative debugging tool.

Common Pitfalls

  • Forgetting optimizer.zero_grad() — gradients silently accumulate across batches.
  • Using the wrong loss function for the task (e.g., MSE for classification).

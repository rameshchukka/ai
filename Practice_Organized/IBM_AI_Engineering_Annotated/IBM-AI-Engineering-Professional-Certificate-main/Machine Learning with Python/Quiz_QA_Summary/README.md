# Machine Learning with Python — Quiz Questions & Answers

The five Week 1–5 quizzes from the repo were **PDF screenshots of the already-submitted
Coursera quiz**, not text-based PDFs — I rendered each to an image and read the selected
answers directly (the filled radio buttons / checked boxes visible in each screenshot).

Every one of the 25 selected answers (5 questions × 5 quizzes, 3 points each = 15/15 per
quiz) was checked against standard ML fundamentals and confirmed correct — consistent with
a full-marks submission.

## Files
| File | Topic |
|---|---|
| `Week1_Intro_to_Machine_Learning_QA.md` | Supervised vs. unsupervised, what ML is/isn't, regression definition |
| `Week2_Regression_QA.md` | Multiple linear regression, out-of-sample accuracy, polynomial & non-linear regression |
| `Week3_Classification_QA.md` | Classification vs. regression, logistic regression, kNN, information gain |
| `Week4_Clustering_QA.md` | k-means (local vs. global optimum), DBSCAN, dissimilarity metrics, centroid init |
| `Week5_Recommender_System_QA.md` | Content-based vs. collaborative filtering, cold start, memory- vs. model-based |

## Format
Each file lists every question exactly as it appeared, marks the **selected answer**, and adds
a short **"Why"** explanation — so these work as genuine study material (understand the
reasoning), not just a bare answer key.

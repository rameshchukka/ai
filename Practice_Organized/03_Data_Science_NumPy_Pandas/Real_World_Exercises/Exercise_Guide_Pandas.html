📘 Concept Notes

What is a DataFrame?

A DataFrame is a labeled, 2D table — like a spreadsheet or SQL table you can manipulate in code. Every column has a name and a dtype; every row has an index.

Why groupby is central

`groupby('col').agg(...)` splits your data into groups by a column's values, applies a function to each group, then combines the results — the exact pattern behind almost every business report ('total X by Y').

Merging tables

Real data lives in more than one table. `.merge(how=...)` combines them on a shared key column, mirroring SQL joins: inner (only matches), left/right (keep one side's rows), outer (keep everything).

Datetime & resampling

Once a date column is your index, `.resample('W')` (or 'D', 'M', etc.) lets you roll up data into time buckets — the standard way to build daily/weekly/monthly reports.

💡 Tips & Pitfalls

Tips

  • Run .info(), .describe(), and .isna().sum() immediately after loading any dataset.
  • Use .loc[] for filtered assignment to avoid the SettingWithCopyWarning.
  • Named aggregations (`.agg(total=('col','sum'))`) are more readable than positional ones.

Common Pitfalls

  • Chained indexing like `df[df.x>0]['y']=1` silently fails to update the original.
  • Forgetting `parse_dates=` when reading a CSV with date columns.
  • Defaulting to an inner join without considering whether rows will silently disappear.

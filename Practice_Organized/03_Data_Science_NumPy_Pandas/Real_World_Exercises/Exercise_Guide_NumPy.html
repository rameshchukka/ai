📘 Concept Notes

What is vectorization?

Instead of looping over elements one at a time in Python, NumPy lets you apply an operation to an entire array at once. The loop still happens, but inside fast, compiled C code instead of the slow Python interpreter — often 10-100x faster.

What is broadcasting?

Broadcasting is NumPy's rule for combining arrays of different shapes without you manually copying data to match sizes. A shape like (4,3) can combine with (3,) because the trailing dimension matches — NumPy 'stretches' the smaller array virtually.

What is boolean masking?

A boolean mask is an array of True/False values the same shape as your data. `arr[mask]` pulls out only the True positions — this is how you filter arrays, equivalent to a SQL WHERE clause.

Why axis matters

`axis=0` collapses down the rows (result: one value per column). `axis=1` collapses across the columns (result: one value per row). Getting this backwards is the most common NumPy mistake beginners make.

💡 Tips & Pitfalls

Tips

  • If you write `for i in range(len(arr))` on a NumPy array, stop — there's almost always a vectorized way.
  • Sketch shapes on paper before combining arrays — most broadcasting errors are caught this way.
  • `arr[mask]` returns a copy; modifying it won't change the original array.

Common Pitfalls

  • Confusing axis=0 (down columns) with axis=1 (across rows).
  • Using Python's `and`/`or` instead of `&`/`|` on boolean arrays (raises an error or gives wrong results).
  • Comparing floats for exact equality after arithmetic — use np.isclose instead.

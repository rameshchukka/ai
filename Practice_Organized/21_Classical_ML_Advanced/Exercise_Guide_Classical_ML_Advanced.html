📘 Concept Notes

Kernel trick (SVM)

SVMs find the maximum-margin boundary between classes. The 'kernel trick' lets them do this in a higher-dimensional space implicitly, without ever computing that space directly — enabling non-linear boundaries efficiently.

Why Naive Bayes still works well

Despite assuming features are independent (rarely true), Naive Bayes is fast, needs little data, and performs surprisingly well — especially for text, where word-independence is 'wrong but useful'.

Boosting vs. bagging

Random forest (bagging) trains many independent trees and averages them. Gradient boosting trains trees sequentially, each one correcting the previous ensemble's errors — usually more accurate but more prone to overfitting if untuned.

Cross-validated tuning

GridSearchCV/RandomizedSearchCV split the training set internally (cross-validation) to evaluate each hyperparameter combination — this keeps your true test set untouched until final evaluation.

💡 Tips & Pitfalls

Tips

  • Always scale features before SVM.
  • Gradient boosting usually beats random forest on tabular data but needs more careful tuning.
  • Use GridSearchCV/RandomizedSearchCV, not manual tuning against the test set.

Common Pitfalls

  • Tuning hyperparameters against the test set (leakage).
  • Using PCA components as if they were still interpretable original features.
  • Applying ARIMA to non-stationary data without differencing.

📘 Concept Notes

Matrices as transformations

A matrix multiplying a vector isn't just 'numbers combining' — it's a geometric transformation (rotation, scaling, projection). This mental model makes PCA, neural network layers, and embeddings far more intuitive.

Distributions model real randomness

Normal distributions model continuous measurements clustering around an average (heights, errors); Poisson models counts of events in a fixed window (calls per hour); Binomial models yes/no outcomes repeated n times.

Bayes' theorem and base rates

Bayes' theorem formally combines prior belief with new evidence. The classic surprising result: a '99% accurate' test can still have low positive predictive value if the condition it detects is rare — the base rate matters enormously.

p-values are about surprise, not truth

A p-value measures how surprising your observed data would be if the null hypothesis were true. Small p-value = surprising = evidence against the null. It is NOT the probability the null hypothesis is true.

💡 Tips & Pitfalls

Tips

  • Think of a matrix as a function that transforms vectors.
  • Always compute a confidence interval alongside a point estimate.
  • Compute required A/B test sample size before launching, not after peeking at results.

Common Pitfalls

  • Peeking at A/B test results early and stopping as soon as they look significant.
  • Confusing correlation with causation.
  • Treating p < 0.05 as 'proven true' rather than 'unlikely under the null hypothesis'.

🌍 Real-World Use Cases

  • PCA for dimensionality reduction
  • A/B testing a new UI or model version before full rollout
  • Statistical significance testing for any data-driven product decision

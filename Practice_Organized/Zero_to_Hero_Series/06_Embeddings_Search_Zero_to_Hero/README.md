# 🔎 Embeddings & Search: Zero to Hero — Guided Lab

Build a search engine from scratch: tokenization, bag-of-words, cosine similarity, TF-IDF, BM25, semantic search with embeddings, hybrid fusion, chunking, and proper evaluation (precision@k, recall@k, MRR). 100% offline with NumPy.

## The teaching format (every chapter)
- 📖 **Theory** (detailed) — the concept explained properly, not just name-dropped
- 🧠 **Mental model** — the intuition to hold in your head
- 🖼️ **ASCII diagram** — a visual of how it fits together
- 🔬 **Worked example** — runnable code you execute and read
- ⚡ **Pro tips** and ⚠️ **Common traps** — what actually trips people up
- ✏️ **Your Turn** exercise → ✅ **Solution** (revealed right after)

## Chapters
1. The search problem & corpus
2. Tokenization & bag-of-words
3. Cosine similarity
4. TF-IDF (smart keyword weighting)
5. BM25 (industry keyword standard)
6. Embeddings & semantic search
7. Hybrid search
8. Chunking documents
9. Evaluating search (precision@k, recall@k, MRR)
10. 🏆 Capstone: complete mini search engine

# 🔗 LangChain: Zero to Hero — Guided Lab

Understand LangChain from the inside out by building tiny working versions of its core ideas: Runnables and the pipe (LCEL), prompt templates, chains, output parsers, memory, retrieval chains, tools, and agents. 100% offline; real LangChain syntax shown alongside.

## The teaching format (every chapter)
- 📖 **Theory** (detailed) — the concept explained properly, not just name-dropped
- 🧠 **Mental model** — the intuition to hold in your head
- 🖼️ **ASCII diagram** — a visual of how it fits together
- 🔬 **Worked example** — runnable code you execute and read
- ⚡ **Pro tips** and ⚠️ **Common traps** — what actually trips people up
- ✏️ **Your Turn** exercise → ✅ **Solution** (revealed right after)

## Chapters
1. What LangChain is (the Runnable idea)
2. Prompt templates
3. The LLM component
4. Chains & LCEL (the pipe operator)
5. Output parsers
6. Memory (stateful conversations)
7. Retrieval chains (RAG in LangChain)
8. Tools
9. Agents (LLM chooses the tool)
10. 🏆 Capstone: tool-using assistant chain

## Requirements
```
pip install --upgrade pip   # no external deps; optional: langchain, langchain-openai
```

Every concept is built as a minimal Runnable-shaped stand-in, then mapped to real LangChain code at the end.

Work top to bottom. Attempt every ✏️ exercise before opening its ✅ solution, and finish with
the 🏆 capstone.

# 🤝 A2A Protocol (Agent-to-Agent): Zero to Hero — Guided Lab

The open protocol for independent AI agents to discover each other, negotiate a task, and collaborate without sharing internal code or memory. Build Agent Cards, a discovery registry, the task lifecycle, sync/async exchange, multi-agent delegation, and security scoping from scratch. 100% offline; concepts map to the real A2A protocol.

## The teaching format (every chapter)
- 📖 **Theory** (detailed) — the concept explained properly, not just name-dropped
- 🧠 **Mental model** — the intuition to hold in your head
- 🖼️ **ASCII diagram** — a visual of how it fits together
- 🔬 **Worked example** — runnable code you execute and read
- ⚡ **Pro tips** and ⚠️ **Common traps** — what actually trips people up
- ✏️ **Your Turn** exercise → ✅ **Solution** (revealed right after)

## Chapters
1. Why A2A? MCP vs A2A
2. The Agent Card (capability advertisement)
3. Discovery: finding the right agent
4. Tasks & the task lifecycle
5. Messages & artifacts
6. A synchronous request/response exchange
7. Long-running tasks & status polling
8. Multi-agent delegation (an orchestrator using A2A)
9. Security & trust boundaries
10. 🏆 Capstone: a small A2A network solving a compound task

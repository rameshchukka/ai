# 📊 Classical Machine Learning: Zero to Hero — Guided Lab

The algorithms that predate deep learning and still power most production tabular-data systems: linear/logistic regression, decision trees, random forests & boosting, k-NN, k-Means, SVMs, and PCA — built from math first principles, then with scikit-learn.

## The teaching format (every chapter)
- 📖 **Theory** (detailed) — the concept explained properly, not just name-dropped
- 🧠 **Mental model** — the intuition to hold in your head
- 🖼️ **ASCII diagram** — a visual of how it fits together
- 🔬 **Worked example** — runnable code you execute and read
- ⚡ **Pro tips** and ⚠️ **Common traps** — what actually trips people up
- ✏️ **Your Turn** exercise → ✅ **Solution** (revealed right after)

## Chapters
1. The ML problem: fitting a function to data
2. Linear regression (from scratch + scikit-learn)
3. Logistic regression (classification)
4. Decision trees
5. Ensembles: random forests & boosting
6. k-Nearest Neighbors
7. k-Means clustering
8. Support Vector Machines (concept)
9. Dimensionality reduction: PCA
10. 🏆 Capstone: full classical-ML pipeline on real data

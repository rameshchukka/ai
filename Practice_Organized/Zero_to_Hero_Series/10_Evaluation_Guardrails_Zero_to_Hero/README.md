# 🛡️ Evaluation & Guardrails: Zero to Hero — Guided Lab

The discipline that turns an LLM demo into a shippable product: building eval sets, accuracy/precision/recall/F1, LLM-as-judge, input and output guardrails, PII redaction, prompt-injection defense, and regression testing. 100% offline; maps directly to production eval and guardrail tooling.

## The teaching format (every chapter)
- 📖 **Theory** (detailed) — the concept explained properly, not just name-dropped
- 🧠 **Mental model** — the intuition to hold in your head
- 🖼️ **ASCII diagram** — a visual of how it fits together
- 🔬 **Worked example** — runnable code you execute and read
- ⚡ **Pro tips** and ⚠️ **Common traps** — what actually trips people up
- ✏️ **Your Turn** exercise → ✅ **Solution** (revealed right after)

## Chapters
1. Why evaluate? (the ship-blind problem)
2. Building an evaluation set
3. Exact-match & keyword metrics
4. Classification metrics (precision, recall, F1)
5. LLM-as-judge
6. Input guardrails (validation & injection defense)
7. Output guardrails (safety, format, PII)
8. Regression testing
9. Eval + guardrail harness
10. 🏆 Capstone: guarded, evaluated pipeline

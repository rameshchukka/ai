# 🔥 PyTorch: Zero to Hero — Guided Lab

A complete, self-contained course taking you from 'what is a tensor?' to training, evaluating, and saving real neural networks — understanding every moving part.

## The teaching format (every chapter)
- 📖 **Theory** (detailed) — the concept explained properly, not just name-dropped
- 🧠 **Mental model** — the intuition to hold in your head
- 🖼️ **ASCII diagram** — a visual of how it fits together
- 🔬 **Worked example** — runnable code you execute and read
- ⚡ **Pro tips** and ⚠️ **Common traps** — what actually trips people up
- ✏️ **Your Turn** exercise → ✅ **Solution** (revealed right after)

## Chapters
1. Tensors — creation, shapes, dtypes, devices
2. Tensor operations & broadcasting
3. Autograd — automatic differentiation
4. Manual gradient descent → nn.Module
5. The canonical 5-step training loop
6. Datasets & DataLoaders
7. Real project: regression (house prices)
8. Real project: classification
9. Saving, loading & inference
10. 🏆 Capstone: end-to-end Iris classifier

## Requirements
```
pip install torch scikit-learn numpy
```

The lab uses tiny synthetic + sklearn datasets so it runs offline in seconds.

Work top to bottom. Attempt every ✏️ exercise before opening its ✅ solution, and finish with
the 🏆 capstone.

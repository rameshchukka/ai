📘 Concept Notes

What a tensor really is

A tensor is an n-dimensional array like a NumPy array, but with two superpowers: it can run on a GPU, and it can track gradients for automatic differentiation. Everything in PyTorch is tensors flowing through operations.

Autograd is the whole game

Training = adjusting parameters to reduce a loss. Autograd records every operation in a computation graph on the forward pass, then replays it backward (chain rule) to compute each parameter's gradient automatically when you call .backward().

The 5-step training loop

Nearly every PyTorch model trains with the same rhythm: zero_grad -> forward -> loss -> backward -> step. Memorize this rhythm and you can read almost any training code.

Normalization and eval mode

Two things beginners skip that break real training: normalizing inputs (unscaled features make training unstable) and switching to model.eval() + torch.no_grad() for inference.

💡 Tips & Pitfalls

Tips

  • Sanity-check by overfitting a tiny batch before a long run.
  • Wrap inference in torch.no_grad() to save memory/time.
  • Say matmul shapes out loud before writing them.

Common Pitfalls

  • Forgetting optimizer.zero_grad() so gradients accumulate.
  • Adding softmax before CrossEntropyLoss (double-applies it).
  • Loading a state_dict into a different architecture.

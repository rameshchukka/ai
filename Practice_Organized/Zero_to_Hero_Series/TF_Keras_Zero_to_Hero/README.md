# 🧠 TensorFlow & Keras: Zero to Hero — Guided Lab

From tensors and GradientTape autodiff up to the high-level Keras workflow (compile → fit → evaluate), the Functional API, callbacks, and saving/loading — building real regression and classification models.

## The teaching format (every chapter)
- 📖 **Theory** (detailed) — the concept explained properly, not just name-dropped
- 🧠 **Mental model** — the intuition to hold in your head
- 🖼️ **ASCII diagram** — a visual of how it fits together
- 🔬 **Worked example** — runnable code you execute and read
- ⚡ **Pro tips** and ⚠️ **Common traps** — what actually trips people up
- ✏️ **Your Turn** exercise → ✅ **Solution** (revealed right after)

## Chapters
1. Tensors & basic ops
2. Variables & GradientTape (autodiff)
3. The Keras Sequential API
4. Compile → Fit → Evaluate workflow
5. The Functional API
6. Real project: regression
7. Real project: classification + learning curves
8. Callbacks (EarlyStopping, checkpoints)
9. Saving & loading models
10. 🏆 Capstone: breast-cancer classifier

## Requirements
```
pip install tensorflow scikit-learn numpy
```

Runs offline on small sklearn datasets. Use `tensorflow-cpu` if you don't have a GPU.

Work top to bottom. Attempt every ✏️ exercise before opening its ✅ solution, and finish with
the 🏆 capstone.
